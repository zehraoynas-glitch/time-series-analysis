# Time Series Analysis and Forecasting

Comprehensive time series analysis and forecasting project utilizing macroeconomic industrial production data.

## Project Overview
This repository contains statistical modeling scripts and an analytical report evaluating industrial production index data. The study covers classical decomposition, regression models, exponential smoothing, and Box-Jenkins (ARIMA) methodologies.

## Key Analyses & Methods
* **Dataset:** TCMB EVDS (Central Bank of the Republic of Turkey - Electronic Data Delivery System) Industrial Production Index for the Manufacture of Textiles (TP.SAN.Y01).
* **Decomposition Methods:** Additive and Multiplicative Decomposition Models.
* **Regression Analysis:** Additive and Multiplicative Trend Regressions.
* **Smoothing Techniques:** Additive and Multiplicative Winters Exponential Smoothing.
* **Box-Jenkins Models:** ARIMA model identification, estimation, and forecasting.

## Tech Stack
* **Language:** R
* **Methodologies:** Time Series Decomposition, Exponential Smoothing, ARIMA Modeling
